# Chitra

A Canva-style design/image editor that runs entirely in the browser (Fabric.js, no build step).

Run: `python3 -m http.server 8000` then open http://localhost:8000 (or just open `index.html`).

Features: canvas size presets, shapes, text (fonts/size/style/align/spacing), image upload / drag-drop / paste,
image adjustments & filters, layers (order, lock, duplicate, flip, align), templates, undo/redo, zoom,
save/open projects (`.chitra.json`), export PNG/JPG.
